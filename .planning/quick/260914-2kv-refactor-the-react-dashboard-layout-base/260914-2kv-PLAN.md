# Quick Plan: Refactor React Dashboard Layout

## Goal
Port the structural layout and element positioning from `BlareX_Sense_Complete_Dashboard_v5.html` into `frontend/src/` while strictly keeping the existing dark theme aesthetic and live backend API wiring.

## Tasks

### Task 1: Refactor Layout Architecture (Sidebar + Sticky Topbar)
- **Files**: `frontend/src/components/Layout.js`, `frontend/src/components/DashboardNavbar.js`
- **Action**:
  - Implement a sidebar navigation + sticky topbar structure.
  - Sidebar provides brand logo (`BlareXSense`), navigation items (Overview/Home, Devices, Activity/Alerts, Profile/Settings), and footer status ("BlareXSense V1 • Cloud connected").
  - Topbar includes:
    - Location / Space selector dropdown (`Home`, `Office`, or room-based).
    - Top actions: Notifications indicator, Add Device trigger, and User avatar / profile button.
    - Mobile bottom bar navigation on small screens.
- **Verify**: Responsive layout renders cleanly on desktop and mobile screens.
- **Done**: Sidebar and topbar positioning matches prototype layout with dark styling.

### Task 2: Refactor Dashboard Home View (KPI Strip, 3-Column Grid, 1.2fr:0.8fr Split)
- **Files**: `frontend/src/pages/DeviceManagement.js`
- **Action**:
  - Add summary KPI chip strip: Online devices count, Presence detected, Loads active, System alerts.
  - Re-architect device cards into a responsive 3-column grid (`devicegrid`):
    - Mini device icon preview with room tag.
    - Prominent Presence status banner (`Present` in green soft pill, `Away` in subtle gray pill).
    - Footer with Operating Mode pill ("Auto", "Manual", "Fall/Sleep") and interactive Relay Switch toggle.
  - Add view toggle: Grid View vs Tabular List View (`.tablecard` showing Device, Room, Status, Presence, Mode, Actions).
  - Implement the 1.2fr : 0.8fr Quick Section:
    - Left (1.2fr): Quick Actions ("Turn all OFF", "All Auto Mode", "Night Routine", "Noise Calibrate").
    - Right (0.8fr): Live Alert Feed showing recent system notifications and timestamps.
- **Verify**: Live device data, polling updates, and relay toggle endpoints work smoothly.
- **Done**: Dashboard view matches prototype visual arrangement while preserving dark theme and real endpoints.

### Task 3: Implement Slide-Out Inspect Drawer (`DeviceInspectDrawer.js`)
- **Files**: `frontend/src/components/DeviceInspectDrawer.js`, `frontend/src/pages/DeviceManagement.js`
- **Action**:
  - Build slide-out drawer (using Radix Sheet) triggered from device cards or table rows.
  - Tabbed interface:
    - **Control Tab**: Hero live presence banner, connected load relay switch, operating mode selector (Auto / Manual / Fall / Sleep), and 10s room noise calibration trigger (`POST /api/devices/{id}/calibrate`).
    - **Presence Tab**: Detection range slider, sensitivity level, and absence auto-OFF delay.
    - **Settings Tab**: Device name, room, copy device ID & API key (`POST /api/devices/{id}/rotate-key`), Wi-Fi RSSI, and firmware info.
- **Verify**: Drawer opens and closes smoothly, triggers relay and calibration API calls, and preserves dark styling.
- **Done**: All device inspect and configuration actions are accessible via the slide-out drawer.
